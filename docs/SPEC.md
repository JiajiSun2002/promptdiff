# PromptDiff 需求规格

完整版（含路线图、风险）：https://claude.ai/artifact/LMnTnq5ei8bBqX14kgSgWv

## 处理管线
| 步骤 | 内容 | 在哪里完成 |
| --- | --- | --- |
| ① 母语输入 | 用户选源语言、写 prompt | 前端 |
| ② 翻译 + 抽取 | 一次调用：英文译文 + 双语 scene graph（实体/属性/关系，两边共用 ID，含字符位置）+ 逐条检查问题 | 文本模型 |
| ③ 生成两组图 | 同一图像模型、同一参数，每种语言 N 张 | 图像模型 |
| ④ 逐条检查 | 每张图一次调用：对每条要求判定 yes / no / unsure + 理由 + 实体边界框 | 视觉模型 |
| ⑤ 差异计算 | 检查矩阵 + 差异分类 | 前端（`src/lib/diff.ts`） |
| ⑥ 联动视图 + 标注 | 文本 · scene graph · 图像三处联动高亮；用户圈选并说明意图 | 前端 |
| ⑦ 合成编辑指令 | 标注 + 文字 → 编辑指令（用户可预览、可改） | 文本模型 |
| ⑧ 生成改进图 | 以两组图为参考图做图像编辑，然后回到 ④ 重新检查 | 图像模型 |

检查问题有依赖关系（参考 DSG）：先问实体是否存在，再问属性和关系；父项为 no 时子项记为 `n/a`。

## 差异分类（每条要求）
| 分类 | 条件 | 含义 |
| --- | --- | --- |
| both_pass | 两种语言都 yes | 无需关注 |
| both_fail | 两种语言都 no | 模型能力问题，与语言无关 |
| src_only_fail | src 为 no，en 为 yes | 可能的语言效应（重点展示） |
| en_only_fail | en 为 no，src 为 yes | 可能的语言效应或翻译问题 |
| uncertain | 任一为 unsure | 请用户确认 |

每种语言有多张图时用通过率（如 2/3），阈值 0.5 判定 pass/fail。用户覆盖（userOverride）优先于模型判定。

## 功能需求
| ID | 模块 | 需求 | 优先级 | 里程碑 |
| --- | --- | --- | --- | --- |
| F1 | Create | 选择源语言，输入母语 prompt | Must | 中期 |
| F2 | Create | LLM 译成英文且可编辑；显示回译供核对 | Must（回译 Should） | 中期 |
| F3 | 抽取 | 一次调用抽取双语 scene graph，共用 ID，带字符位置 | Must | 中期 |
| F4 | 抽取 | 两个图不一致时在生成前提示「翻译漂移」 | Should | 中期 |
| F5 | 生成 | 同一模型同一参数，每种语言 N 张（中期 N=1，期末 2–4） | Must | 中期 |
| F6 | 检查 | 逐条判定 yes/no/unsure + 理由 + 边界框 | Must | 中期 |
| F7 | 对比 | 三处联动：prompt 短语 / 图节点 / 图像区域 | Must | 中期 |
| F8 | 对比 | 检查矩阵（行=要求，列=图），突出只在一种语言失败的行 | Must | 中期 |
| F9 | 对比 | scene graph 节点按检查结果着色；用户可修正节点或判定 | 显示 Must / 编辑 Should | 中期 / 期末 |
| F10 | 标注 | 点边界框选对象，选意图（保留外观/保留位置/修改/删除）+ 评论，自动编号 | Must | 中期 |
| F11 | 标注 | 手绘圈选任意区域 | Should | 期末 |
| F12 | Refine | 标注 + 文字合成编辑指令，以两组图为参考生成改进图 | Must | 期末 |
| F13 | Refine | 改进图重新检查，显示相对原图哪些要求改善 / 退步 | Must | 期末 |
| F14 | History | 迭代树，可回到任一节点重新分支；IndexedDB 持久化 | Should | 期末 |
| F15 | 设置 | API key、模型 ID、N、图像尺寸；Mock 模式开关 | Must | 中期 |
| F16 | 演示 | 预置案例；会话导入 / 导出 JSON，离线可演示 | Must | 中期 |
| F17 | 研究 | Baseline 模式（只有两个 prompt + 两张图）、任务计时、事件日志导出 CSV | Should | 期末 |

## 中期（2026-12-02）验收
现场跑通 ①–⑥：输入 → 翻译与抽取 → 生成 → 逐条检查 → 检查矩阵与联动高亮 → 点击边界框标注。断网时可用 fixture 离线演示。
